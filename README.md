# 🎬 Movie Ratings Exploration

Exploratory data analysis of 500,000+ movie ratings from the MovieLens dataset.

## 🔍 Key Insights

- **Drama and Crime** are the highest-rated genres (avg 3.68)
- **Horror** has the lowest average rating (3.27)
- **Shawshank Redemption** is the top-rated film with 4.50 avg (1,599 ratings)
- Older films (1950s) rated higher (3.88) than modern ones (2010s: 3.56)
- **4.0** is the most common rating given by users

## 📊 Visualisations

- Rating distribution across all users
- Top 10 genres by number of ratings
- Average rating by genre
- Average rating by decade (1950–2010s)
- Top 10 movies by average rating (min 1,000 ratings)
- Number of ratings vs average rating scatter plot

## 🛠 Tech Stack

- **Analysis:** pandas, numpy
- **Visualisation:** matplotlib, seaborn, plotly
- **Database:** SQL (SQLite via Python)
- **Tools:** Jupyter Notebook, Git

## 📁 Dataset

MovieLens 20M Dataset — 20M ratings, 27K movies, 138K users.
Download: [Kaggle](https://www.kaggle.com/datasets/grouplens/movielens-20m-dataset)
